# ПЗ.6 — Работа с Jetpack Compose

Учебный проект по МДК.01.03 «Разработка мобильных приложений»
(специальность 09.02.07 Информационные системы и программирование).

## Что сделано

- **Задание 1.** Создан проект в Android Studio на Jetpack Compose (шаблон Empty Activity);
  в `AndroidManifest.xml` изменены логотип приложения (`android:icon`, `android:roundIcon`)
  и название (`android:label`).
- **Задание 2.** Пройдены уроки 6–10 курса Compose на startandroid.ru:
  1. Урок 6 — состояние (State) и счётчик на `mutableStateOf`.
  2. Урок 7 — `Checkbox` и `TextField`: список задач с зачёркиванием, форма входа с проверкой полей.
  3. Урок 8 — рекомпозиция: наблюдение за перерисовкой экрана через `Log.d` в Logcat.
  4. Урок 9 — `remember`: сравнение состояния с `remember` и без него.
  5. Урок 10 — связка `remember` + `mutableStateOf`.
- **Задание 2.2.** Все изученные элементы размещены на одном экране (`MainActivity.kt`).
- **Задание 3.** Настроены светлая и тёмная темы: своя палитра (primary, secondary, tertiary,
  background, surface) в `Color.kt`, типографика, отличная от стандартной, — `Type.kt`,
  переключение тем — `Theme.kt`.

## Структура проекта

```
app/src/main/java/com/example/composetutorial/
├── MainActivity.kt          # все изученные элементы на одном экране
└── ui/theme/
    ├── Color.kt             # цвета светлой и тёмной темы
    ├── Theme.kt             # переключение светлой/тёмной темы
    └── Type.kt              # типографика
```

## Как запустить

1. Открыть проект в Android Studio (Jellyfish или новее, JDK 17).
2. Дождаться синхронизации Gradle.
3. Запустить Run ▸ Run 'app' на эмуляторе или устройстве с Android 7.0+ (API 24+).
